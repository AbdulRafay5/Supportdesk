# SupportDesk

An IT helpdesk application for reporting, assigning and resolving support tickets.

## Planned stack
- ASP.NET Core and C# for the REST API
- React and TypeScript for the web interface
- SQL Server and Entity Framework Core for persistence
- xUnit for automated tests

## Development status
Early development. The initial milestone is a ticket API with validation, followed by database persistence, authentication and the web interface.
